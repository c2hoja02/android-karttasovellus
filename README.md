# andoird-karttasovellus
Retkikäyttöön suuniteltu Android-karttasovellus marjapaikkojen sekä reittikarttojen luontiin.

## Projektipalaveri

[Projektipalaveri](Projektipalaveri.md) – palaverien esityslistat, muistiinpanot, päätökset ja sovitut tehtävät.

Joka perjantai GitHub Actions luo uuden `Projektipalaveri-YYYY-MM-DD.md`-sivupohjan Suomen päivämäärän mukaan ja avaa siitä pull requestin. Sivu lisätään `main`-haaraan, kun pull request yhdistetään.
